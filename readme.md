# Chatbox

## Requirements
- [VS Code](https://code.visualstudio.com)
- [Git](https://git-scm.com)
- [Node.js](https://nodejs.org/en)

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/MineRaphi/chatbox
```

### 2. Go into the project folder
```bash
cd chatbox
```

### 3. Install dependencies
```bash
npm install
```

### 4. Start the app
```bash
npm run dev
```
